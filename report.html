Diagnostics and history

Legacy data can be imported only when updating the same extension installation/ID. A separately installed extension cannot read the old extension’s storage.

Privacy: the extension only targets ChatGPT pages in the selected Chrome window, contains no external telemetry, and stores up to 5,000 log entries in local Chrome storage. Export logs regularly if you need a longer history. Click the extension icon again to stop. Synthetic mouse input does not move the physical pointer.

Safety: completion needs a positive finished-response action on the latest assistant turn. The absence of a Stop button is not enough. ChatGPT changes its DOM, so this is a best-effort check and cannot guarantee perfect completion detection. Ambiguous Enter delivery quarantines only the affected conversation; all others remain monitored.
